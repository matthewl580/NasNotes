# **App Name**: Nasnotes

## Core Features:

- Note Creation: Quickly create new notes with a text input field.
- Note Listing: View all notes in a clean, reverse-chronological list format.
- Note Titles: Notes can have titles
- Note Grouping: You can group notes together
- Note Combination: You can combine notes
- Note Editing: Edit existing notes directly from the list view or within the note itself.
- Note Deletion: Easily delete notes with a clear and confirmation step.
- Summarization Tool: Use AI tool to summarize the note when note length exceeds token constraints.
- Image Embedding: You should be able to embed images into the notes
- Custom Drawings: You should be able to create and insert custom drawings in it
- Homescreen Notes: All of your notes should be presented on the homescreen, and can have customizable positions on it.
- PWA Availability: It should be available on mobile and the app should be PWA
- Customization: The app should be very customisable (each note can have its own background color, etc)

## Style Guidelines:

- Background color: Very light pastel blue (#F0F8FF) to create a soft and calming atmosphere.
- Primary color: A muted blue (#778899) for text and primary interactive elements, providing a gentle contrast against the background.
- Accent color: Soft peach (#FFDAB9) to highlight important actions or elements.
- Font: 'Inter', a sans-serif font, providing a modern, machined, neutral look for both headers and body.
- Clean and minimal layout with generous white space to avoid clutter and enhance readability.
- Simple, line-based icons for actions such as edit and delete, maintaining the minimalist aesthetic.
- Subtle fade-in and slide-up animations for creating and displaying notes to give a smooth user experience.
